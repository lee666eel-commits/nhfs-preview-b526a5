# 家长布告栏：建表与审批流程

首页「家长布告栏」读两份 Google 表格「发布到网络」的 CSV：**最新动态**（主任投稿 → 校长勾选通过 → 自动上网）与**本月行事历**（每月月头填）。网站不用改代码，只要表格有数据。

流程：主任填 Google 表单 → 回应进表格 → 校长在手机 Google Sheets 勾「校长通过」→ 约 5 分钟后首页出现。

## 一次性建置（约 15 分钟，用学校账号）

> ⚠️ 用 **学校 @nanhwafs.edu.my 账号**建，并把校长室加为编辑者；别建在个人账号，免得人一调走就断。

1. **建表单**「家长布告栏投稿」，设置：只限 nanhwafs.edu.my 用户、收集电子邮件地址。题目**按此顺序**：
   1. 部门（下拉：教务处／训导处／学生事务处／联课处／辅导处／总务处／校长室……）
   2. 标题（简答，必填）
   3. 内容（段落，必填）
   4. 照片（文件上传，图片，最多 5 个）
   5. 影片（文件上传，视频，最多 1 个，选填）
   6. 相关链接（简答，选填，例如董总网址）
2. 表单链接**只发给各处主任**。
3. 表单「回复」→ 链接到新表格。表格里回应分页的栏位应为：A 时间戳记、B 电邮、C 部门、D 标题、E 内容、F 照片、G 影片、H 相关链接。
4. 在 **I1** 写「校长通过」，选 I2:I1000 → 插入 → 复选框。
5. 新增分页「**公开**」，A1 贴（分页名照你表格实际名字改）：
   ```
   =QUERY('表单回复 1'!A:I,"select A,C,D,E,F,G,H where I = true order by A desc format A 'yyyy-mm-dd'",1)
   ```
   这一页只含已通过的稿、不含主任电邮。
6. 新增分页「**行事历**」：A 日期（2026-11-03）、B 活动、C 备注（选填）。整年的都可以先填，首页只显示当月。可直接把 `assets/notice/calendar.csv`（10–12 月家长版，摘自教务处《2026 行事历》）贴进来当起点。
7. 文件 → 共享 → **发布到网络**：分别选「公开」和「行事历」两个分页、格式选 **CSV**，各得一个网址。⛔ 不要发布整份文件或回应分页。
8. 到 Google 云端硬盘，找表单上传文件夹（「家长布告栏投稿 (File responses)」）→ 共享 → 一般访问权限改「知道链接的任何人：查看者」，照片才能在首页显示。
9. 校长：打开表单「回复」→ ⋮ →「获取新回复的电子邮件通知」，有新稿就收到邮件，到表格勾选即可。
10. 把第 7 步两个网址交给飞鑫，填进 `index.html` 的 `NOTICE_CSV`、`CAL_CSV`（在那之前行事历先读站内 `assets/notice/calendar.csv`）。

## 测试

投一篇带照片的测试稿、勾通过，用**无痕窗口**打开第 7 步「公开」的网址，应看到该行；再打开照片网址能看到图。两样都通才算通。

若学校 Workspace 管理员关了「发布到网络」或「知道链接的任何人」，这条路走不通，改用 Apps Script 网页应用出 JSON（另做）。

## 注意

- 撤下一篇：取消勾选即可，约 5 分钟后首页消失。
- 首页只显示最新 6 篇；行事历只显示当月。
- 不要在表单中间插新题目，会让栏位错位；要加题请加在最后，并告诉飞鑫。
- 本机预览示例数据：`index.html?sample`（读本文件夹的 sample-*.csv，内容皆为「示例」）。
