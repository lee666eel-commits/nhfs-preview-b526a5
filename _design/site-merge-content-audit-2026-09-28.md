- **线上 nanhwafs.edu.my（24 页，sitemap.xml 全量）**：本次用 `WebFetch`（服务端抓取 HTML → 转 markdown → 小模型摘要），**不是浏览器实测**。原计划用 claude-in-chrome 浏览器工具实际渲染页面，但本次运行环境浏览器扩展未连接（`Browser extension is not connected`），只能退回 WebFetch。
